# Personal Level Skills

These skills are stored in your home directory and apply to all projects. They represent your personal coding conventions, preferences, and common patterns you use across different genomics projects.

## Installation

Copy these skills to your OpenCode personal skills directory:
```bash
cp -r personal-level/* ~/.opencode/skills/
```

## Skills Included

- **genomics-best-practices.md** - General genomics analysis best practices
- **scientific-reproducibility.md** - Guidelines for reproducible research
- **code-style-conventions.md** - Personal coding style and conventions
